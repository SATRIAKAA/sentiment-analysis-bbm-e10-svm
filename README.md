# TikTok Sentiment Analysis on Indonesia's E10 Fuel Policy using SVM

This project performs sentiment analysis on TikTok comments discussing Indonesia's E10 fuel policy. The sentiment classification uses Lexicon-Based labeling, TF-IDF feature extraction, and a Linear Support Vector Machine (SVM).

The project was developed as an undergraduate thesis in Informatics Engineering.
## Features

- TikTok comment preprocessing
- Case Folding
- Tokenization
- Stopword Removal
- Stemming (Sastrawi)
- Lexicon-Based Sentiment Labeling
- TF-IDF Feature Extraction
- Support Vector Machine (Linear Kernel)
- Model Evaluation
- Confusion Matrix
- Hyperplane Visualization
- WordCloud
- Sentiment Distribution Visualization
