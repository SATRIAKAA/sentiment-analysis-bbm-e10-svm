# TikTok Sentiment Analysis on Indonesia's E10 Fuel Policy using SVM

This project performs sentiment analysis on TikTok comments discussing Indonesia's E10 fuel policy. The sentiment classification uses Lexicon-Based labeling, TF-IDF feature extraction, and a Linear Support Vector Machine (SVM).

The project was developed as an undergraduate thesis in Informatics Engineering.
## Features

- TikTok comment preprocessing
- Case Folding
- Tokenization
- Stopword Removal
- Stemming (Sastrawi)
- Lexicon-Based Sentiment Labeling
- TF-IDF Feature Extraction
- Support Vector Machine (Linear Kernel)
- Model Evaluation
- Confusion Matrix
- Hyperplane Visualization
- WordCloud
- Sentiment Distribution Visualization

## Hyperplane Visualization

The figure below illustrates the decision boundary (hyperplane) generated by the Linear Support Vector Machine (SVM) after reducing the TF-IDF feature space into two dimensions using Principal Component Analysis (PCA).

Each point represents a TikTok comment projected onto a 2-dimensional space, while different markers indicate the sentiment classes (Negative, Neutral, and Positive). The colored background represents the decision regions learned by the SVM model.

Although the Linear SVM successfully separates the sentiment classes, several data points remain clustered near the decision boundary and overlap with other classes. This indicates that some comments have similar textual characteristics despite belonging to different sentiment categories. Such overlap is mainly influenced by the limitations of lexicon-based sentiment labeling and the complexity of informal social media language, including slang, sarcasm, ambiguous expressions, and contextual meanings.

Overall, the visualization demonstrates that the Linear SVM is capable of learning the general decision boundary for sentiment classification while highlighting the challenges of separating semantically similar comments in a high-dimensional text dataset.
